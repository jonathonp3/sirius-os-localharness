# Vendored browser assets

- **markdown-it 14.1.0** — MIT — https://github.com/markdown-it/markdown-it
- **highlight.js 11.11.1** (common build + github-dark theme) — BSD-3-Clause — https://github.com/highlightjs/highlight.js
- **DOMPurify 3.2.6** — Apache-2.0 OR MPL-2.0 — https://github.com/cure53/DOMPurify

These files are embedded in the `harness` binary and served from `/assets/` on loopback.

- **Typo.js** — BSD-3-Clause — https://github.com/cfinke/Typo.js
- **en_AU Hunspell dictionary** — from the Fedora `hunspell-en-AU` package (see its license) — bundled for offline spellchecking.
